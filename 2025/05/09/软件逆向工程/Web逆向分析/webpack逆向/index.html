什么是Webpack

Webpack 是一个现代 JavaScript 应用程序的静态模块打包工具。它的核心功能是将应用程序中的所有资源（如 JavaScript 文件、CSS 文件、图片等）视为模块，并通过依赖关系将它们打包成一个或多个优化后的静态资源文件。Webpack 的主要目的是解决前端开发中模块化、依赖管理和资源优化的问题。它通过入口文件（entry point）递归地构建依赖图，将所有的模块和资源整合在一起，最终生成适合生产环境使用的静态文件。

Webpack 的核心概念包括入口（entry）、输出（output）、加载器（loader）和插件（plugins）。入口定义了打包的起点，Webpack 会从入口文件开始分析依赖关系；输出则指定了打包后文件的存放位置和命名规则。加载器用于处理非 JavaScript 文件（如 CSS、图片等），将它们转换为有效的模块；插件则用于执行更广泛的任务，如代码压缩、环境变量注入等。Webpack 还支持开发服务器（DevServer），提供热更新（Hot Module Replacement）等功能，极大地提升了开发效率。

上面就是框架部分，看懂了这个框架的运行流程，就明白了webpack的原理。

简单来说，webpack实际上就是一个以加载器为核心的，以加载器的某一个模块为入口(代码里是r(10))，分模块打包，最终返回exports进行调用的一种打包工具

也就是说r函数实际上就是一个加载器，把所有需要的模块全部加载进来，这样就能让后面的代码进行调用。

webpack代码扣取/补环境的时候，需要把整个加载器的代码都拿到本地，然后通过调用加载器函数r(10)得到需要的模块对象。
