云平台

基础知识

硬件 作用
路由器 连接不同网络，决定数据包走哪条路
交换机 在同一网络内连接多台设备
防火墙 过滤进出网络的流量，阻止非法访问
负载均衡器 把流量分发到多台服务器
网卡 设备上网的硬件接口
概念 是什么
IP地址 网络设备的唯一标识
域名 IP的易记别名
DNS 把域名翻译成IP的服务
带宽 单位时间能传多少数据
延迟 数据从A到B的时间
丢包 数据在传输中丢失了
TCP 可靠的、有连接的传输协议
UDP 不可靠的、无连接的传输协议
HTTP/HTTPS 浏览器和服务器之间的通信协议
SSH 远程登录服务器的加密协议
概念 是什么 通俗理解
VPS（虚拟专用服务器） 一台物理机虚拟出多台独立服务器 一栋楼隔成多间独立公寓
云服务器 / 弹性云服务器 VPS 的企业版，支持秒级升降配、按量付费 VPS 是手动挡轿车，云服务器是自动挡+随时换轮胎
裸金属服务器 非虚拟化的物理服务器，直接交付整台机器 你买下整栋楼（不是一间公寓），完全独享
容器（Docker） 轻量级虚拟化，共享宿主机内核，只隔离进程 公寓里的一个个独立隔间（共享水电管道）
Serverless / 函数计算 你只写代码，平台帮你运行、扩容、计费（按调用次数） 你只管写菜谱，餐厅按订单帮你做菜并收钱
概念 是什么 通俗理解
对象存储（如 AWS S3 / 阿里云OSS / Cloudflare R2） 无限容量的云端硬盘，按存储量+请求次数计费 巨大的网盘，专门存文件（图片、视频、备份）
块存储（云硬盘） 挂载到云服务器的虚拟硬盘 你电脑的 C 盘/D 盘，但存在云端
文件存储（NAS） 多台服务器共享的文件夹 公司共享网盘，多台电脑都能访问
CDN（内容分发网络） 全球缓存静态文件 前置仓库
边缘存储（Cloudflare R2） 对象存储 + CDN 一体化，只收存储费，免流出流量费 仓库直接建在便利店旁边，取货不要运费
概念 是什么 通俗理解
VPN 公共网络上建立加密隧道，改变网络位置 秘密地道
VPC（虚拟私有云） 云上隔离出来的私有网络，你可以自定义 IP 段、子网、路由表 你在云上买了一块地，自己修路、划车位、设门禁
负载均衡 把流量分发到多台后端服务器 餐厅的排号机
NAT 网关 让多台私有网络内的服务器共享一个公网 IP 出去 公司前台，所有快递都由她签收再分发
专线 物理层面连接本地机房和云厂商的专用线路 你从家里挖一条地道直通公司，不经过公共马路
防火墙 / 安全组 控制进出云服务器的网络流量规则 机场安检，只放行允许的端口和 IP
DDoS 防护 抵御大流量攻击（把带宽堵满） 在门口加装防洪闸，水来了分流掉
WAF（Web 应用防火墙） 检测 HTTP/HTTPS 请求中的恶意内容（SQL 注入、XSS 等） 安检员不仅看行李，还检查你的话有没有危险词
IAM（身份与访问管理） 控制谁（用户/程序）能访问哪些云资源 公司门禁卡，不同人不同权限
KMS（密钥管理服务） 集中管理加密密钥 保险柜的钥匙统一锁在另一个更安全的保险柜
合规认证（GDPR, SOC2, ISO27001） 证明你的云服务符合某地/行业的安全标准 餐厅挂出“卫生 A 级”牌照

云厂商

国内

阿里云

国内市场份额第一，亚太地区领先的云厂商。

优势：产品线最全，国内节点最多，备案体验相对顺畅，生态（万网、钉钉）整合好。注意：国际节点覆盖尚可（美、欧、东南亚、中东），但部分国家对国内厂商有数据主权顾虑。

  • 是否适合出海： 适合，尤其是亚太市场。阿里云在东南亚（新加坡、印尼、菲律宾）节点布局早，当地认可度高。但进军欧美市场不如AWS/GCP有品牌优势。

腾讯云

国内第二，游戏、社交、音视频领域强势。

优势：游戏解决方案成熟，实时音视频（TRTC）技术强，与微信/QQ生态打通。注意：国际节点比阿里云少，海外品牌认知度较低。

  • 是否适合出海：谨慎适合。主要适合游戏出海（尤其东南亚、日韩）和社交/直播类应用。通用Web应用出海不如选国际大厂。

**华为云 **

政企市场强势，技术驱动型厂商。

优势：底层技术（芯片、网络）自研，AI能力（盘古大模型）强，安全合规投入大。注意：受国际政治因素影响，部分国家/地区可能对华为品牌敏感。

  • 是否适合出海：受限适合。适合不受地缘政治影响的区域（如东南亚、中东、非洲、拉美），以及政企、制造、能源类出海项目。欧美市场不建议。

国外

全球头部三大云厂商

这三家实力最强，全球覆盖最广，是企业出海的首选，但新用户通常需要国际信用卡/双币卡，且部分对中国用户的风控较严。

  1. Amazon Web Services (AWS) / 亚马逊云

    • 特点：市场占有率第一，产品最全，全球区域最多（包括美、欧、日、韩、新加坡等）。
    • 优势：稳定、生态强大、12个月免费套餐（有限制）。
    • 注意：流量按量付费，超量会产生较高账单，需设置预算告警。

  2. Microsoft Azure / 微软云

    • 特点：与Windows、Active Directory、SQL Server等微软生态深度集成。
    • 优势：企业混合云方案强，AI和机器学习服务优秀。
    • 注意：计费模型复杂，新用户有免费额度。

  3. Google Cloud Platform (GCP) / 谷歌云

    • 特点：全球高速骨干网，尤其擅长大数据分析和AI（如TensorFlow）。
    • 优势：网络质量高，到亚洲的延迟表现好。新用户通常送300美元试用金。
    • 注意：需绑定信用卡，避免滥用导致扣费。

高性价比/对国内开发者友好

这些厂商注册相对简单（部分支持支付宝/银联），价格更亲民，是国内个人开发者和初创团队常用的选择。

  1. Vultr

    • 特点：按小时计费，随时删除实例（仅收使用时长）。支持支付宝、微信支付。
    • 优势：机房选择多（包括日本、新加坡、美国洛杉矶等），有高频CPU选项。
    • 注意：适合个人网站、科学用途、测试环境。

  2. DigitalOcean

    • 特点：以简洁易用著称，文档非常完善。支持支付宝（通过部分第三方）。
    • 优势：基础套餐（1核1GB）性价比高，社区活跃。
    • 注意：适合学习Linux和部署中小型应用。

  3. Linode（现被Akamai收购）

    • 特点：老牌VPS厂商，稳定性口碑很好。支持支付宝。
    • 优势：性能均衡，客服响应快。东京节点对国内延迟友好。
    • 注意：适合追求稳定性的个人开发者。

  4. BandwagonHost (搬瓦工)

    • 特点：主打CN2 GIA优质线路，对国内访问速度优化极好。支持支付宝。
    • 优势：电信/联通用户延迟低、丢包少。
    • 注意：价格比Vultr/DigitalOcean稍高，且配置较低。

特色服务与特定用途

这些厂商在特定领域（免费、无服务器、欧洲市场、WordPress托管）有突出优势。

  1. Oracle Cloud (甲骨文云)

    • 特点：提供永久免费的ARM云主机（最高4核24GB内存）。
    • 优势：适合预算极度有限但需要一定性能的开发者。
    • 注意：需要验证信用卡（预授权），且免费资源有抢不到或突然被回收的风险。

  2. Cloudflare

    • 特点：主力是CDN和安全服务，但也推出了Cloudflare Workers（边缘计算）和 R2（对象存储）。
    • 优势：按请求量付费，适合无服务器场景。
    • 注意：适合API后端、静态网站托管，不适合传统长时间运行的虚拟机。

  3. 欧洲厂商 (Hetzner, OVH)

    • 特点：价格非常低（例如Hetzner的AX系列独服）。
    • 优势：性价比极高，适合面向欧洲用户的应用。
    • 注意：机房主要在德国、法国、加拿大，到国内延迟高。

WordPress托管与管理平台

这类服务专注于简化建站和服务器运维，适合不同技术水平的用户。

  1. Hostinger

    • 特点：便宜、入门级，自带建站工具。
    • 优势：价格极低，支持支付宝，适合预算有限的新手。
    • 注意：适合个人博客、小型网站。

  2. SiteGround

    • 特点：WordPress官方强推、管理完善。
    • 优势：客服好，稳定性高，适合正经运营的WordPress站点。
    • 注意：续费价格很贵，存储空间偏小。

  3. Cloudways

    • 特点：云服务器管理平台，帮你管理VPS（如DigitalOcean、AWS等）。
    • 优势：兼顾性能与易用性，按小时计费，适合有点技术但不想折腾运维的开发者。
    • 注意：比直接买VPS贵（含管理费），无邮件服务。

小众与廉价VPS（进阶/玩具级）

这类厂商价格低，但稳定性、性能或品牌知名度参差不齐，适合特定需求的进阶玩家。

  1. v.ps

    • 特点：欧洲小众高端VPS，主打优化线路（对中国电信/联通友好）。
    • 优势：到国内延迟低、丢包少。
    • 注意：价格中高，品牌较小，适合对国内访问质量有要求的用户。

  2. RackNerd

    • 特点：美国廉价VPS，主打便宜、流量大。
    • 优势：年付$10-30，性价比高，适合不在意延迟的个人项目（如备份、离线下载）。
    • 注意：到国内延迟较高，晚高峰可能丢包。

  3. ByteVirt

    • 特点：极度廉价的玩具VPS。
    • 优势：月付$1-2，适合学习、折腾、挂轻量脚本。
    • 注意：稳定性一般，超售严重，不要放重要数据。

  4. ClawCloud

    • 特点：新兴厂商，具体信息不明（可能是新品牌或小众IDC）。
    • 优势：无（或价格极低）。
    • 注意：需谨慎对待，存在跑路风险，建议观望。
