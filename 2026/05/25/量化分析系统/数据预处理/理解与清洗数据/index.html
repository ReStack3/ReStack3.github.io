理解与清洗数据

基本库

NumPy

数组计算的数学基础

其设计核心是：“一切皆为同质化的多维数组，运算向量化，避免Python循环。”

NumPy 的核心是 ndarray（N-dimensional array），它假设数据是同质的（所有元素类型相同，如 float64）。它的哲学是：将数学运算从元素级别提升到数组级别。可以用数学公式的方式写代码，而不是用循环的方式。

我们使用时需要注意抓住要点：

核心要点 解释
向量化思维 不要用 for 循环遍历数组，直接用数组运算：a + b 而不是 for i in range(len(a)): c[i]=a[i]+b[i]
广播机制 不同形状的数组可以运算，NumPy 会自动扩展维度。理解 (3,4) 与 (4,) 如何运算
索引即视图 切片返回的是原数组的视图（不复制内存），修改会影响原数组。copy() 可以打破这种关联
轴的概念 axis=0 是垂直方向（跨行），axis=1 是水平方向（跨列）

Pandas

表格数据的操作语言

其设计哲学是“一切都是带标签的二维表格，操作以列为中心，语法像 Excel 和 SQL 的杂交体。”

Pandas 的核心是 DataFrame（带行索引和列名的二维表格）。它的哲学是：让数据的筛选、分组、合并、变形变得像说话一样自然。Pandas 可以用人类处理表格的方式操作数据，而不是用计算机的底层逻辑。

核心要点 解释
向量化 + 自动对齐 两个 DataFrame 相加时，会自动按行索引和列名对齐，不匹配的变 NaN
链式操作 df.dropna().query('age>30').groupby('city').mean() 一步一步处理
区分 .loc 和 .iloc .loc['行标签', '列名'] 按标签索引；.iloc[0,1] 按整数位置索引
长格式 vs 宽格式 melt() 把宽变长，pivot() 把长变宽，这是 Pandas 最让人困惑但也最强大的地方

Seaborn

统计可视化的声明式语法

“声明式绘图：告诉它你想看什么关系，它选择合适的图表和美学。”

Seaborn 的核心是数据与美学映射。它的哲学是：只需要指定数据、变量和图表类型，颜色、刻度、图例、统计变换都自动完成。这是对 Matplotlib（命令式，你要一步步画）的根本性颠覆。

用统计学家的语言（变量关系、分布、分类对比）来画图，而不是用图形学家的语言（点、线、颜色、坐标）。

核心要点 解释
数据是长格式 Seaborn 天生喜欢“整洁数据”：每行一个观测，每列一个变量
hue / size / style 这三个参数是核心：用颜色/大小/样式来映射第三个/第四个变量
图形级 vs 轴级 relplot(), displot(), catplot() 是图形级（支持分面）；scatterplot(), histplot() 是轴级（在现有 Axes 上画）
统计变换自动完成 sns.barplot() 自动计算均值+置信区间，sns.violinplot() 自动算 KDE

理解数据

探索性数据分析

当拿到一个新的数据集时，下面是基本的工作流程。

  1. 数据有没有组织？数据是以表格形式存在、有不同的行列，还是以非结构化的文本格式存在？
  2. 每列的数据是定量的还是定性的？单元格中的数代表的是数值还是字符串？
  3. 每列处于哪个等级？是定类、定序、定距，还是定比？
  4. 可以用什么图表？条形图、饼图、茎叶图、箱线图、直方图，还是其他？

探索性数据分析和数据可视化 ：

数据结构的有无

拿到一个新的数据集后，首要任务是确认数据是结构化还是非结构化的。

  • 结构化（有组织）数据：可以分成观察值和特征的数据，一般以表格的形式组织（行是观察值，列是特征）。
  • 非结构化（无组织）数据：作为自由流动的实体，不遵循标准组织结构（例如表格）的数据。通常，非结构化数据在我们看来是一团数据，或只有一个特征（列）。

定量数据和定性数据

为了完成对数据的判断，我们从区分度最高的顺序开始。在处理结构化的表格数据时(大部分时候都是如此），第一个问题一般是：数据是定量的，还是定性的？

  • 定量数据本质上是数值，应该是衡量某样东西的数量。
  • 定性数据本质上是类别，应该是描述某样东西的性质。

基本示例：

  • 以华氏度或摄氏度表示的气温是定量的；
  • 阴天或晴天是定性的；
  • 白宫参观者的名字是定性的；
  • 献血的血量是定量的。

数据的 4 个等级

我们已经可以将数据分为定量和定性的，但是还可以继续分类。数据的 4 个等级是：

  • Nominal（定类）：不能比大小，不能算加减。（如：红色、蓝色）
  • Ordinal（定序）：能比大小，但不能算加减。（如：好、中、差）
  • Interval（定距）：能算加减，但不能算乘除。（如：年份 2023-2000=23年）
  • Ratio（定比）：能算乘除，有绝对零点。（如：面积、价格、个数）

每个等级都有不同的控制和数学操作等级。了解数据的等级十分重要，因为它决定了可以执 行的可视化类型和操作。

定类等级

定类等级是数据的第一个等级， 其结构最弱。 这个等级的数据只按名称分类。 例如， 血型（ A、B、 O 和 AB 型）、动物物种和人名。这些数据都是定性的。

核心特征：数据仅用于分类或命名，表示类别或组别。没有任何数量关系或顺序关系。只能计算频数、众数。不能进行加减乘除。数字在这里只是“标签”，没有数学意义。比如，用1代表男，2代表女，并不意味着2比1“大”或“好”。

对于每个等级，我们都会简要介绍可以执行的数学操作，以及不可以执行的数学操作。在这个等级上，不能执行任何定量数学操作，例如加法或除法。这些数学操作没有意义。因为没有加法和除法，所以在此等级上找不到平均值。当然了，没有“平均名”或“平均工作”这种说法。

例子：

  • 性别（男、女）
  • 婚姻状况（未婚、已婚、离异）
  • 颜色（红、蓝、绿）
  • 城市名称（北京、上海、广州）

定序等级

定类等级为我们提供了很多进一步探索的方法。向上一级就到了定序等级。定序等级继承了。
定类等级的所有属性，而且有重要的附加属性：

定序等级的数据可以自然排序；有了“顺序”或“等级”的概念，但差异不明确。

这意味着，可以认为列中的某些数据比其他数据更好或更大。和定类等级一样，定序等级的天然数据属性仍然是类别，即使用数来表示类别也是如此。

和定类等级相比，定序等级多了一些新的能力。在定序等级，我们可以像定类等级那样进行
计数，也可以引入比较和排序。因此，可以使用新的图表了。不仅可以继续使用条形图和饼图，
而且因为能排序和比较，所以能计算中位数和百分位数。对于中位数和百分位数，我们可以绘制
茎叶图和箱线图。

核心特征：数据可以分类和排序，但类别之间的差异是未知的或没有意义的。可以计算频数、众数、中位数、百分位数。仍然不能进行加减乘除。

例子：

  • 学历（小学、初中、高中、大学）-> 我们知道大学 > 高中 > 初中，但不知道“大学和高中”之间的差距是否等于“高中和初中”之间的差距。
  • 满意度（非常不满意、不满意、一般、满意、非常满意）
  • 比赛名次（第一名、第二名、第三名）-> 我们知道第一比第二好，但不知道好多少。

定距等级

在定类和定序等级，我们一直在处理定性数据。即使其内容是数，也不代表真实的数量。在定距等级，我们摆脱了这个限制，开始研究定量数据。在定距等级，数值数据不仅可以像定序等级的数据一样排序，而且值之间的差异也有意义。这意味着，在定距等级，我们不仅可以对值进行排序和比较，而且可以加减。

在定距等级上可以进行加减，这改变了整个游戏规则。既然可以把值加在一起，就
能引入两个熟悉的概念： 算术平均数（就是均值）和标准差。

核心特征：数据可以分类、排序，并且差值具有实际意义。然而，没有真正的绝对零点。可以计算频数、众数、中位数、均值、标准差。可以进行加法和减法，但不能进行乘除（因为零点是任意的）。

例子：

  • 温度（摄氏度或华氏度）-> 20°C 和 30°C 之间的差异与 30°C 和 40°C 之间的差异相同，都是10°C。但0°C 并不意味着“没有温度”，所以我们不能说40°C是20°C的“两倍热”。
  • 年份（公元2024年，公元1990年）-> 年份的差值（时间间隔）是有意义的，但公元0年是一个任意的起点，不代表“没有时间”。

反例：
一个经典的反例是李克特量表。因为可以排序，所以我们把李克特量表归为定序等级。但是
需要注意的是，对其做减法并没有意义。如果在李克特量表上将 5 减去 3，得出的结果 2 既不代
表数字 2，也不代表 2 这个类别。因此，李克特量表的减法很困难。

定比等级

在这个等级上，可以说我们拥有最高程度的控制和数学运算能力。和定距等级一样，我们在定比等级上处理的也是定量数据。这里不仅继承了定距等级的加减运算，而且有了一个绝对零点的概念，可以做乘除运算。

  • 核心特征：数据的最高等级。具备定距等级的所有特性，并且拥有一个真正的、有意义的绝对零点。可以进行所有数学运算，包括加、减、乘、除。可以计算所有统计量，包括几何平均、变异系数等。

在定比等级，我们可以进行乘除运算。虽然看起来没什么大不了，但是这些运算可以让我们对这个等级上的数据进行独特的观察，而这在低等级上是无法做到的。我们先看几个例子，了解一下这意味着什么

例子：

  • 身高、体重、年龄 -> 0公斤表示“没有重量”，所以80公斤是40公斤的两倍重。
  • 收入、销售额 -> 0元表示“没有收入”。
  • 反应时间、距离、数量。

相关系数矩阵热力图

热图是用颜色深浅表示数值大小的矩阵可视化。在代码中：

  • X轴和Y轴：都是数据集的特征名（列名）
  • 每个小格子：表示两个特征之间的相关系数值
  • 颜色深浅：表示相关性的强弱
    • 🔴 红色越深 → 正相关性越强（接近 +1）
    • 🔵 蓝色越深 → 负相关性越强（接近 -1）
    • ⚪ 白色/浅色 → 相关性弱（接近 0）

注意矩阵是对称的：A与B的相关性 = B与A的相关性，只看上三角或下三角即可

基本清洗：

缺失值

识别

特征增强的第一种方法是识别数据的缺失值，这可以让我们更好地明白如何使用真实世界中的数据。通常，数据集会因为各种原因有所缺失，例如调查时没有记录某些观察值等。分析数据并了解缺失的数据是什么至关重要，这样才可以决定下一步如何处理这些缺失值。

使用 df.isnull() 或 df.isna()（两者在pandas中基本等价）可以得到一个布尔类型的DataFrame，其中True表示该位置是缺失值。

可视化缺失值分布

在进行任何处理之前，先直观地了解缺失情况。

分析缺失模式

了解缺失值的产生机制对于选择处理方法至关重要，它将影响我们如何选择什么方法处理缺失值。

  • 完全随机缺失(MCAR)：缺失与任何变量都无关
  • 随机缺失(MAR)：缺失与已观测到的变量有关
  • 非随机缺失(MNAR)：缺失与未观测到的变量有关（本身的值有关）

标准化与归一化

消除数据中不同特征因量纲和分布范围不同而产生的偏差，使模型更公平地对待每一个特征，加速模型收敛。

归一化

将数据缩放到一个固定的范围，通常是 [0, 1]。

$$
Xnorm=(X−Xmin)⁡/(Xmax−Xmin)
$$
适用场景：数据分布没有明显的正态性。需要将数据压缩到特定范围（如图像像素值）。使用梯度下降优化的模型（如神经网络）。缺点是对异常值非常敏感。一个极端异常值会压缩正常数据的分布区间。

标准化

将数据转换为均值为0，标准差为1的正态分布。

$$
Xstd=(X−μ)/σ
$$
适用场景：数据近似服从正态分布，或至少是对称分布。存在异常值（标准化对异常值的鲁棒性比归一化稍好）。许多机器学习算法（如SVM、逻辑回归、PCA）的默认假设。缺点是转换后的数据不在一个固定的范围内。

方法 适用场景 优点 缺点
Z-Score 标准化 数据近似正态分布；存在异常值；大多数机器学习算法 对异常值相对鲁棒；保持分布形状 输出范围无限制
Min-Max 归一化 需要固定范围；神经网络；图像处理 输出范围固定；直观易懂 对异常值敏感
行归一化 文本数据；聚类分析；余弦相似度计算 保持样本间角度关系；适用于稀疏数据 改变特征间的关系

Z-Score 标准化

该方法基于原始数据的均值和标准差进行标准化。经过处理的数据符合标准正态分布，即均值为0，标准差为1。

$$
( z = \frac{x - \mu}{\sigma} )
$$
特点：对异常值相对鲁棒，输出范围无限制（可能产生很大或很小的值），保持原始分布形状

输出结果分析：所有特征的均值都接近0，所有特征的标准差都接近1，异常值（Age=200）仍然存在，但被标准化到一个相对位置

Min-Max 归一化

将数据缩放到一个固定的范围，通常是[0, 1]。

$$
x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
$$

对异常值非常敏感，输出范围固定为[0, 1]，保持原始分布形状

行归一化

这种方法按行进行归一化，确保每个样本（行）的特征向量具有相同的范数。

$$
( x_{\text{norm}} = \frac{x}{|x|} )
$$

常用于文本数据或余弦相似度计算，将每个样本投影到单位球面上，保持样本间的角度关系
